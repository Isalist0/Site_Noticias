Notícias Raízes Express
Descrição
Notícias Raízes Express é um portal de notícias desenvolvido utilizando HTML5 e CSS3, com o objetivo de simular uma plataforma digital de informação organizada por editorias.

O projeto apresenta notícias relacionadas a tecnologia, cultura e clima, utilizando uma estrutura semântica moderna e um layout planejado para proporcionar uma experiência de leitura clara e intuitiva.

Além de demonstrar conhecimentos em desenvolvimento web front-end, o projeto aplica boas práticas de organização de conteúdo, separação entre estrutura e estilização e utilização de recursos multimídia para enriquecer a navegação.

Objetivo do Projeto
O principal objetivo deste projeto é desenvolver uma página web estática capaz de reproduzir elementos encontrados em grandes portais de notícias, explorando conceitos fundamentais do desenvolvimento web.

Entre os objetivos específicos estão:

Aplicar marcação semântica utilizando HTML5;
Utilizar CSS3 para personalização visual;
Organizar conteúdos jornalísticos em diferentes categorias;
Trabalhar com imagens e elementos multimídia;
Desenvolver um layout limpo e de fácil leitura;
Praticar a separação entre estrutura e apresentação;
Aprimorar conhecimentos em desenvolvimento de interfaces web.
Funcionalidades Implementadas
O portal conta com diversas funcionalidades visuais e estruturais:

Cabeçalho Institucional
A aplicação possui um cabeçalho responsável por apresentar a identidade do portal e fornecer acesso às principais áreas da página.

Navegação
Através do menu de navegação, o usuário pode localizar rapidamente as diferentes editorias presentes no portal.

Seções de Notícias
As notícias são exibidas de forma organizada, permitindo que o leitor identifique rapidamente o tema abordado.

Imagens Ilustrativas
Cada matéria possui imagens relacionadas ao assunto tratado, contribuindo para uma melhor contextualização das informações apresentadas.

Estrutura Semântica
O projeto utiliza elementos semânticos do HTML5 para melhorar a organização do código e a acessibilidade.

Rodapé
A página contém um rodapé institucional responsável por apresentar informações sobre autoria e contato.

Editorias Disponíveis
Tecnologia & Mercado
Esta editoria apresenta conteúdos relacionados às transformações provocadas pela Inteligência Artificial no mercado financeiro e em setores estratégicos da economia.

Os temas abordados incluem:

Inteligência Artificial aplicada a investimentos;
Automação de processos financeiros;
Ferramentas inteligentes para análise de mercado;
Tendências tecnológicas;
Impactos da IA no ambiente corporativo.
Cultura & Cinema
A editoria de cultura traz uma cobertura especial sobre o cenário cinematográfico internacional, com destaque para o Oscar 2025.

Entre os assuntos abordados estão:

Principais indicados da premiação;
Destaques da indústria cinematográfica;
Participação do cinema brasileiro;
Reconhecimento internacional do filme Ainda Estou Aqui;
Importância cultural das produções nacionais.
Clima & Previsão do Tempo
A seção de clima apresenta informações sobre eventos meteorológicos extremos e seus impactos na população.

Os conteúdos incluem:

Onda de calor registrada em diversas regiões do país;
Recordes de temperatura;
Alertas meteorológicos;
Impactos das mudanças climáticas;
Recomendações para períodos de calor intenso.
